# 03. 화면 구성 및 와이어프레임

PinFlick의 주요 화면 구조를 텍스트 와이어프레임으로 정의합니다. (현재 구현 기준)

---

## 앱 네비게이션 구조

```
스플래시 → (최초)온보딩 → 로그인(Google 전용) → MainShell
                                                  │
                          ┌───────────────────────┴───────────────────────┐
                          │           MainShell (하단 탭 + 중앙 FAB)         │
                          │  🏠 홈 | 🗺 친구지도 | (➕) | 🖼 갤러리 | 👥 친구 │
                          └────────────────────────────────────────────────┘
  · 가운데 ➕ FAB: 탭=브이로그 등록 마법사 / 길게=빠른 체크인
  · 선택 탭은 탭 컬러 알약으로 강조 (홈=블루·지도=시안·갤러리=퍼플·친구=핑크)
```

---

## 화면 1 — 로그인 (Google 전용)

```
┌─────────────────────────┐
│        PinFlick         │  ← 로고 + 이름
│ ┌─────────────────────┐ │
│ │  G  Google로 로그인  │ │
│ └─────────────────────┘ │
│ ┌─────────────────────┐ │
│ │ ⓘ PinFlick은 구글   │ │  ← 구글 계정 필수 안내
│ │   계정으로만 로그인   │ │     + "구글 계정 만들기" 링크
│ └─────────────────────┘ │
│ (웹) APK 다운로드 / 앱설치│
│  이용약관 · 개인정보처리방침│
└─────────────────────────┘
```
> 카카오/Apple/게스트(둘러보기)는 제거됨.

---

## 화면 2 — 홈 (피드)

```
┌─────────────────────────┐
│ PinFlick      🔔   👤   │  ← 알림함 / 프로필 아바타
│ [전체][그룹칩...] 정렬↕  │  ← 친구 그룹 필터 + 날짜/거리 정렬
├─────────────────────────┤
│ ┌─────────────────────┐ │
│ │ 👤 작성자 · 장소·주소 │ │  ← VlogCard (1열 가로 카드)
│ │ [사진/영상  1/N]     │ │
│ │ ♥  💬  ↗      🔖 👁 │ │  ← 좋아요·댓글·공유·저장·조회
│ └─────────────────────┘ │
│ ┌─────────────────────┐ │
│ │ 체크인 카드 ...       │ │
│ └─────────────────────┘ │
├─────────────────────────┤
│ 🏠   🗺   ➕   🖼   👥  │
└─────────────────────────┘
```

## 화면 3 — 친구 실시간 지도 (Live Map) ★핵심

```
┌─────────────────────────┐
│ ←  친구 N명 접속중   [필터]│
│                         │
│     [구글 지도 전체]      │
│      (친구 아바타 마커)    │
│   💖정확  🙈안개원  🥷고정 │  ← 모드별 표시
│     · 체크인 이모지 마커    │
│                    [📍내위치]│
├─────────────────────────┤
│  🙂 상태 설정   🙈 부끄럼 모드│  ← 내 상태 / 프라이버시 모드
└─────────────────────────┘

친구 마커 탭 → 상세 시트(상태·갱신시간·호출하기)
체크인 마커 탭 → 체크인 카드(+댓글)
```

## 화면 4 — 빠른 체크인 시트 (➕ 길게)

```
┌─────────────────────────┐
│ 📍 빠른 체크인           │
│ [📍][🍕][☕][🍻]... 이모지 │
│ 빠른입력: 점심중 카페 ...  │
│ [ 한 줄 메시지 (선택)    ]│
│ ◎ 37.62, 127.07 · 주소   │
│ [현재위치 새로고침][지도선택]│
│ 표시시간: [1h][6h][오늘][24h]│
│ 공개범위: 🌐 전체공개 ▾   │
│ [        체크인         ]│
└─────────────────────────┘
* 수정 시 동일 시트("체크인 수정" 모드)
```

---

## 화면 5 — 브이로그 등록 마법사 (➕ 탭)

```
Step1 미디어 선택(멀티 사진/영상, 웹=파일·모바일=촬영)
Step2 카테고리 이모지
Step3 제목 + 2줄 스토리 + 위치 보정
      [현재위치 새로고침][지도에서 선택][주소로 등록]
Step4 공개 범위 + 미리보기 → 발행
```

## 화면 6 — 플레이어 (영상↔지도 동기화)

```
┌─────────────────────────┐
│ ←      제목         ⋮   │
│   [영상 / 사진 캐러셀]    │
│ ▶ ───●──── 1:23 / 5:00  │
├─────────────────────────┤
│ [구글 지도] ── 이동경로    │  ← 재생 타임코드와 마커 동기화
│     📍(GPS 보간 마커)     │     (전체화면 토글)
│ 📍 장소명 · 주소          │
│ ♥ 좋아요  💬 댓글  ↗ 공유 │
└─────────────────────────┘
```

```
└─────────────────────────┘
```

## 화면 8 — 갤러리 (그리드 + 포토맵)

```
[그리드 탭] 썸네일 그리드   /   [포토맵 탭] 지도 위 클러스터 마커
```

---

## 화면 9 — 친구 / 프로필

```
[친구] 친구 목록 · 검색 · QR · 그룹 관리 · 관계등급/개별모드 설정
[프로필] 내 정보 · 내 브이로그 · 저장한 브이로그 · 설정/로그아웃
[알림함] 받은 호출(Ping) + 친구 요청
```

## 주요 컴포넌트

| 컴포넌트 | 설명 | 재사용 |
|---------|------|--------|
| `VlogCard` | 피드 카드(미디어·소셜액션) | 홈 |
| `CheckInSheet` | 체크인 등록·수정 시트 | FAB 롱프레스, 수정 |
| `MapPickerSheet` / `LocationActionButton` | 지도 위치 선택·보정 | 마법사, 체크인, vlog 수정 |
| `EmojiPickerRow` | 카테고리 이모지 선택 | 마법사, vlog 수정 |
| `VisibilityPickerChip` | 공개 범위 선택 | 마법사, 체크인, 수정 |
| `CommentsSheet` | 댓글/답글/멘션 | 카드, 플레이어, 체크인 |
| `NewVersionBanner` | 웹 OTA 갱신 배너 | 전역 |
| `FirstRunCoachmarks` | 첫 로그인 가이드 | MainShell |
| 아바타 마커(LiveMap) | 친구 위치 마커(꼭지점=좌표) | 친구지도 |

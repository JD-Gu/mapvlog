# 02. 사용자 시나리오

PinFlick의 핵심 사용 흐름을 시나리오로 정의합니다. (친구 위치 공유 + 위치 기반 브이로그/체크인)

---

## 사용자 유형

| 유형 | 설명 |
|------|------|
| 친구 | 서로 친구를 맺고 실시간 위치·일상을 공유하는 사용자 (기본) |
| 기록자 | 브이로그·체크인을 적극적으로 남기는 사용자 |
| 관람자 | 친구들의 피드·지도를 주로 둘러보는 사용자 |

> 모든 기능은 로그인(구글 전용) 후 사용합니다. 비로그인 둘러보기는 제공하지 않습니다.

---

## 시나리오 1 — 온보딩 & 로그인

```
1. 앱/웹 실행 → 스플래시(PinFlick 로고)
2. (최초) 온보딩 슬라이드
3. 로그인 화면 — Google 로그인만 제공
   · 구글 계정 필수 안내 + "구글 계정 만들기" 링크
4. 로그인 → 홈 진입
5. (첫 로그인) 3단계 코치마크 가이드
   · 하단 메뉴 → 가운데 ➕ 버튼 → 위치 공개 모드(베프/부끄럼/잠수)
6. 알림 권한 요청(FCM) — 호출·친구요청·댓글 푸시용
```

---

## 시나리오 2 — 친구 맺기

```
1. [친구] 탭 → 검색 또는 QR
   · 닉네임/이메일 검색, 또는 내 QR 보여주기 / 상대 QR 스캔
2. 친구 요청 전송
3. 상대에게 FCM 푸시("👋 새 친구 요청") + 알림함에 표시
4. 상대가 수락 → 양방향 친구 성립
5. 친구별 관계 등급 설정 (그룹 베이스라인)
   · 💖 베프(정확) / 🙈 부끄럼(대략) / 🥷 잠수(숨김)
   · 필요 시 개별 오버라이드(🎯 항상 정확 / 🥷 항상 잠수 / 🔗 그룹 따름)
```

---

## 시나리오 3 — 친구 실시간 지도 (핵심)

```
1. [친구지도] 탭 진입 (위치 권한 요청 최초 1회)
2. 내 위치가 프라이버시 모드에 따라 가공되어 공유
   · 베프=정확, 부끄럼=약 500m 안개, 잠수=숨김/마지막 위치 고정
3. 친구 아바타 마커 표시 (마커 꼭지점이 실제 좌표)
   · 최근 6시간/만료 전 친구 체크인도 작은 이모지 마커로 표시
4. 친구 마커 탭 → 상세 시트 (상태·갱신시간·호출하기)
5. 호출(Ping): 친구를 콕 찔러 위치 확인 요청 → 상대에게 푸시
6. 절전: 정지/이동/배터리에 따라 위치 갱신 주기 자동 조절
```

---

## 시나리오 4 — 체크인 (빠른 위치 공유)

```
1. 가운데 ➕ 버튼 길게 누르기 → 빠른 체크인 시트
2. 이모지 + 빠른 입력/한 줄 메시지 선택
3. 위치 확인 (현재위치 새로고침 / 지도에서 선택 / 주소 자동)
4. 표시 시간 선택 (1시간 / 6시간 / 오늘 종료 / 24시간)
5. 공개 범위 선택 (전체 / 그룹 / 나만)
6. [체크인] → 친구 피드·지도에 즉시 노출
7. 표시 시간 경과 → 지도에서 숨김 + 서버가 자동 삭제
```

---

## 시나리오 5 — 브이로그 등록 (마법사)

```
1. 가운데 ➕ 버튼 탭 → 등록 마법사
2. 사진(멀티)/영상 선택 (웹=파일선택, 모바일=촬영/갤러리)
   · 영상은 압축, 촬영본은 폰 갤러리 자동 저장
3. 카테고리(이모지) 선택 → 지도 마커 색 자동
4. 제목 + 2줄 스토리
5. 위치 보정 (현재위치 새로고침 / 지도에서 선택 / 주소로 등록)
6. 공개 범위 선택 → 발행
7. 등록 후 피드/지도/갤러리에 노출 (수정 화면에서 사진·위치·공개범위 재편집)
```

---

## 시나리오 6 — 피드 & 소셜

```
1. [홈] 피드 — 친구들의 vlog/체크인 실시간 스트림
2. 카드 상호작용: 좋아요 · 저장(북마크) · 이모지 리액션 · 공유
3. 댓글/답글/@멘션 → 대상자에게 FCM 푸시(스레드 참여자 전원)
4. 카드 탭 → 플레이어 (영상↔지도 GPS 동기화)
5. [갤러리] 그리드 + 포토맵으로 위치 기반 탐색
6. 알림함: 받은 호출 + 친구 요청
```

---

## Use Case (텍스트)

```
[사용자(로그인 필수)]
  ├── 친구 맺기 (검색/QR) · 요청 수락
  ├── 친구 실시간 지도 보기 · 호출(Ping)
  ├── 프라이버시 모드 설정 (베프/부끄럼/잠수, 친구별 오버라이드)
  ├── 체크인 (만료 시간 지정)
  ├── 브이로그 등록/수정/삭제
  ├── 피드 탐색 · 좋아요/저장/리액션/댓글
  └── 갤러리(포토맵) 탐색
```

---

## 예외 처리

| 상황 | 처리 |
|------|------|
| 위치 권한 거부 | 안내 → 설정 유도. 지도/체크인 제한 |
| 알림 권한 거부 | 푸시 미수신 (인앱 알림함은 동작) |
| GPS 부정확 | 위치 보정(새로고침/지도선택/주소)으로 직접 수정 |
| 네트워크 실패 | 재시도 안내, 업로드 실패 시 보존 |
| 잠수 모드 친구 | 내 지도에서 마지막 위치 고정 또는 숨김 |
| 만료된 체크인 | 지도 즉시 숨김, 서버 정시 배치로 삭제 |
